## Shan Thomas

I write pipelines and small tools for microbial sequencing data, mostly amplicon and metagenomic reads from lakes, soils and old sediments. R first, Nextflow for anything that has to run twice.

### Working on

## Shan Thomas

I build tools that make microbial sequencing analysis easier to run and easier to teach: Shiny apps, R packages and browser-based R. Mostly R, with Nextflow on SLURM for the heavy lifting.

My research is on ancient and environmental DNA in freshwater systems. 

### Things here you can use

| Repo | What it does |
|---|---|

| [MicrobeStudio](https://github.com/shanptom/MicrobeStudio) | Shiny app for metabarcoding analysis without writing code. Taxonomy, diversity, indicator taxa. [Try it](https://microbestudio.pipettestopixels.com) |
| [RLMS](https://github.com/shanptom/RLMS) | BioRLab, an R classroom that runs entirely in the browser with webR. [Try it](https://biorlab.pipettestopixels.com) |
| [CodeSparkR](https://github.com/shanptom/CodeSparkR) | LLM help inside the R console through OpenRouter. |
| [PolishGBIF](https://github.com/shanptom/PolishGBIF) | Dockerized Shiny dashboard for GBIF occurrence data. |
| [AWS_Amplicon database](https://github.com/shanptom/AWS_trial) | Amplicon database demo on AWS: S3 for storage, ASVs linked to sample metadata. |
